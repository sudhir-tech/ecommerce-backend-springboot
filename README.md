# ecommerce-backend-springboot
Production-style E-commerce Backend with JWT Authentication, Role-Based Access, Cart, Orders, Pagination, Sorting, and Swagger Documentation.
# 🛒 E-Commerce Backend - Spring Boot

A production-style E-Commerce Backend application built using Spring Boot.

## 🚀 Features

- User Authentication with JWT
- Role-Based Authorization (ADMIN / USER)
- Product Management
- Cart Management
- Order Management
- Inventory Management
- Pagination & Sorting
- Search APIs
- DTO Layer
- Validation Layer
- Exception Handling
- Swagger API Documentation

---

# 🛠️ Tech Stack

- Java 25
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger / OpenAPI

---

# 📦 Modules

## 👤 User Module
- Register User

## 📱 Product Module
- Add Product

## 🛒 Cart Module
- Add to Cart
- Remove from Cart

## 📦 Order Module

# ⚙️ Run Locally

## Clone Repository

```bash
git clone https://github.com/sudhir-tech/ecommerce-backend-springboot.git
```

## Open Project

Import project into Eclipse / IntelliJ.

## Configure Database

Update:

```properties
application.properties
```

with your MySQL credentials.

## Run Application

```bash
mvn spring-boot:run
```
